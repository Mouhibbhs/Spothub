# SpotHub 1.0.1

Changes since 1.0.0:

- Refreshed the app with a rounded, Spotify-inspired interface across Home, Search, Library, playlists, and Now Playing, with smoother transitions and motion.
- Added long-press drag reordering in the queue and swipe-to-remove for songs that are not currently playing.
- Fixed playback position restoration so seeking no longer snaps back to the saved timestamp. Repeat Off, Repeat All, and Repeat One now keep the queue behavior in sync with playback.
- Added a link to the SpotHub GitHub repository in Settings.
- Added versioned GitHub releases that build and attach both Official and Personal Android APKs.
